# Next Level Gaming & Esports Arena - Mobile App

Mobile application for **Next Level Gaming & Esports Arena** (Johannesburg), built for the XHAW5112 Work Integrated Learning project (Scenario 3).

## Features
- Advertises the arena with a modern, high-tech gaming look (neon colours, dark theme)
- Lists the 4 Gaming Packages (R1500 each) and 3 Individual Experiences (R750 each)
- Customers can select more than one booking
- Automatic quotation with discount: 1 booking = 0%, 2 = 5%, 3 = 10%, more than 3 = 15%

## Built with
- React Native (Expo)
- TypeScript

## How to run
1. Install the dependencies with `npm install`
2. Start the app with `npx expo start`
3. Scan the QR code with the Expo Go app
